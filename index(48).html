Setup (one time, 2 min, free):
1. Go to workers.cloudflare.com and sign up
2. Click "Create a Worker"
3. Delete the example code, paste in the proxy code (ask whoever set this up)
4. Click "Deploy"
5. Copy the *.workers.dev URL and paste it above
