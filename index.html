Use proxy Routes streams through your proxy so they play in the browser. Leave on.
Your proxy URL The URL of your Cloudflare Worker.
Website referer The website where the stream normally plays. Many streams only work if you tell the server which website you're coming from. For example: http://www.fawanews.sc/
How to find this: Open the website where the stream normally plays. Copy the URL from the address bar and paste it here.
